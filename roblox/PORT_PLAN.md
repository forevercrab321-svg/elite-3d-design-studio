# Roblox 版 → 和网页版一致：分阶段计划

目标（2026-10-24 创意总监确认）：Roblox 版尽量做到和当前网页版（arena 模式）一致。
网页版功能清单来自对 `game/src/arena/`、`systems/`、`ui/Hud.ts`、`config/` 的逐项盘点。

规则：
- 数值不手抄：网页版 `game/src/config/*.ts` 由 `tools/roblox-config.mjs` 导出成 `roblox/src/shared/WebConfig.luau`，网页改了重新导出即可。
- 单位：1 米 = `Config.STUDS_PER_METER` 格。
- 每个阶段：Lune 离线测试通过 → 用户在 Studio 按 F5 截图 → 对照网页截图验收 → 才进入下一阶段。没截图验收的不算完成。

## 阶段 1 — 底层：网页版的成长数值 + 车辆手感（代码完成，等 Studio 验收）
- [x] 导出网页配置：成长、尺寸等级 0–10、档位 1–5、移动、吸取、镜头、物体（重量、需要的尺寸、破坏方式）。
- [x] 质量模型：起始 5 kg / 0.35 m，直径 = 0.35 ×(质量/5)^(1/3)；能吃 = 直径 ≥ 物体 requiredPower；奖励 = 物体 rewardMass。
- [x] 机器不再是隐身人形：玩家控制一台车（网页公式：最高速、加速时间、转向速度随质量变重、空格冲刺 ×2.1 / 0.28 s / 冷却 1.1 s）。
- [x] 镜头：网页 CameraRig（距离、高度、前瞻、FOV、1.2 s 不动鼠标自动回到车后）。
- [x] 吸入动画：物体飞向进料口、旋转缩小、被吸收；4 级以上先有破坏阶段。
- [x] 连击：1.6 s 内连吃，×1 + 0.1(n−1)，最高 ×1.6。
- [x] 界面：左下质量面板（MASS、TIER n、kg/t、进度条、档位名、NEXT·下一级·所需质量）、+kg 飘字、解锁横幅（UNLOCKED: … / SIZE CLASS n）、升档横幅（TIER n / NOW EATING: …）。

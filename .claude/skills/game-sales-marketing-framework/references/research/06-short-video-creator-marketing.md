## 1. 核心论点（全部未证实·记忆）

1. **前 1–3 秒定生死。** 短视频平台按完播率和互动分发，游戏视频必须一开场就给出冲突或奇观，而不是 Logo 和标题。
2. **「可截屏或可剪辑的时刻」比完整玩法更重要。** 传播单位是一个 5–15 秒的瞬间：翻车、反转、离谱物理、朋友互坑。玩法要主动制造这类时刻。
3. **多人合作的「朋友坑朋友」是 2020 年代最强的病毒机制。** 业界常见的归纳是：Among Us（2020 年由 Twitch 主播带火）、Fall Guys、Lethal Company、Content Warning、Chained Together、R.E.P.O.、PEAK 等「朋友局 / 翻车局」游戏，都靠主播和短视频切片爆发。
4. **创作者是渠道，不是广告位。** 有效做法是给创作者「好内容的原料」（免费 key、抢先体验、专属模式、直播友好功能），而不是买一条硬广。
5. **中国渠道有自己的一套。** 抖音偏向「素材投放 + 达人直播 + 小游戏即点即玩」闭环；B站偏向 UP 主深度实况和梗文化；小红书偏向女性向或种草式图文。
6. **UGC 挑战把玩家变成分发者。** 例如「挑战：X 分钟内吞掉 Y」，玩家录屏投稿，平台话题聚合。

## 2. 方法步骤

### 2.1 短视频素材打法（TikTok / 抖音 / Shorts，未证实·记忆）
1. **钩子（0–3 秒）**：直接给结果或奇观（「我吞掉了整座埃菲尔铁塔」），或者给一个悬念问题。
2. **过程（3–12 秒）**：快速展示反差（小 → 巨大）、翻车、朋友反应。原声和语音反应比配乐更有效。
3. **结尾（12–20 秒）**：反转或回环，诱导重看；在评论区引导「求链接」。
4. **批量生产**：游戏内置回放和一键剪辑（最近 15 秒录屏、自动高光），降低玩家和创作者的制作成本。
5. **小额测试**：同一玩法做 5–10 个钩子变体，看完播率和分享率，选最优的钩子去投放或给达人参考。

### 2.2 主播 / 创作者合作（未证实·记忆）
1. **免费 key 分发**：通过 Keymailer、Lurkit、Woovit 等 key 分发平台，或直接发邮件，按频道规模和品类筛选。
2. **创作者计划**：给创作者专属码或链接，按带来的销售或内购分成（类似 Epic「Support-A-Creator」的机制）。
3. **直播功能**：观众投票、主播专属皮肤、「Streamer Mode」（隐藏房间码、防狙击），降低主播直播的摩擦。
4. **Twitch Drops / 直播掉落**：观看直播即得外观，把观众转化为玩家。
5. **中小主播矩阵优于单个头部主播**：业界常见说法，没有找到可引用的一手数据。

### 2.3 中国渠道（未证实·记忆；权威媒体一篇也未能打开）
1. **抖音 / 抖音小游戏**：即点即玩，无需下载；采用 IAA（广告变现）加 IAP 的混合模式；「巨量引擎投放 + 星图达人 + 直播间挂载小游戏」闭环；2023–2024 年 GameLook、游戏葡萄等媒体多次报道抖音小游戏的增长（具体数字**未证实**，不引用）。
2. **B站**：与 UP 主做实况或整活合作（B站商业合作平台「花火」）；鬼畜和梗文化适合搞笑游戏；弹幕的共同吐槽本身就是传播。
3. **小红书**：品牌合作平台「蒲公英」；适合「可爱 / 解压 / 朋友聚会游戏」类的种草图文和短视频。
4. **微信小游戏**：社交链分享（群分享、好友排行）；与抖音小游戏是两大即点即玩渠道。

## 5. 批评与局限（必须保留）

1. **爆款归因严重后见之明。** 同样打法的大量游戏没有火，「前 3 秒钩子」只是必要条件，不是充分条件。（推断）
2. **素材与玩法不符（「虚假广告」）会损害口碑和平台信任。** 超休闲和小游戏买量素材长期被玩家和媒体批评；国内监管也对游戏广告有要求。（未证实·记忆）
3. **达人效果短、衰减快。** 头部主播一次直播带来的峰值通常几天内就回落；没有留存机制，流量会流失。（未证实·记忆）
4. **成本不透明。** 达人报价、分成比例、平台抽成都缺乏公开权威数据，本次也没能核对。（未证实）
5. **平台算法不可控。** TikTok / 抖音的分发规则频繁变化，「规律」可能半年就失效。（推断）
6. **中国渠道门槛**：国内上线游戏需要版号；抖音、微信小游戏也有资质和备案要求（具体政策**未证实**，需要专项核对）。对海外团队或纯海外发行的项目，中国渠道可能暂时不可行。（未证实·记忆）

## 6. 与其他流派的分歧

- **vs 门户派（04）**：门户派按「留存和时长」放量（Poki 的 Player Fit、CrazyGames 的 Basic → Full），达人派按「可传播性」放量。前者不测传播力，后者不保证留存，二者对「先做什么」的答案相反。
- **vs .io 自发传播派（05）**：.io 派认为好玩法会自然产生可传播时刻；达人派认为时刻必须被设计、被剪辑、被主动投放。
- **vs 买量派**：达人派强调原生内容和信任；买量派强调素材 A/B 测试和 CPI。国内抖音生态把两者合流（投放加星图达人），海外 TikTok 自然流与 Spark Ads 也在合流。
- **内部分歧（未证实·记忆）**：「头部主播一击爆发」和「中小创作者矩阵长期铺量」之争，没有可引用的权威数据能够定论。

## 8. 对 GROW EVERYTHING 的适用性（全部为推断）

> 游戏设定：浏览器 3D 多人 .io，「越吃越大、吞掉整座城市」，四人联机，地图为上海、纽约、巴黎，走搞笑路线。发行路径：自有网页 + CrazyGames / Poki → Steam。收入来源：外观内购、VIP、激励广告。

1. **这个游戏天然是短视频素材机。** 「吞掉东方明珠 / 自由女神 / 埃菲尔铁塔」就是现成的 0–3 秒钩子：地标人人认识，体型反差一眼可懂。建议每张地图设计 3–5 个「地标吞噬高光」，带专属慢镜头、镜头震动和搞笑音效。
2. **内置「一键 15 秒回放」加竖屏导出**：自动截取最近一次吞掉地标或被朋友反吞的片段，附带游戏 URL 水印。这会把每个玩家都变成分发节点，成本远低于买达人。
3. **四人联机对准「朋友局」切片**：设计互坑机制（抢同一栋楼、吞掉队友的车），这是 Lethal Company、R.E.P.O. 式病毒传播的核心（案例未证实，但方向与多人游戏达人切片的常识一致）。
4. **创作者计划分三步**：①Steam 前期给中小主播发 key、加主播模式（隐藏房间码）；②网页版给创作者专属邀请链接和专属皮肤（例如「主播同款金色小笼包」）；③内购分成需要支付和归因体系，放到 Steam 或自有网页阶段再做，门户内的内购受限（见 04）。
5. **UGC 挑战示例**：「60 秒吞掉外滩」「纽约最快吃成哥斯拉」。与游戏内排行榜打通，挑战成绩可截屏分享。
6. **中国渠道要谨慎**：上海地图对国内玩家有天然吸引力，但国内上线涉及版号和小游戏资质（未证实）。建议早期只做**海外 TikTok / Shorts 加 B站海外向或纯内容宣传**，引导玩家到网页版，而不是在国内商业化；是否做抖音小游戏需另行评估。
7. **反作用风险**：素材必须用真实游戏画面，不能拍「理想化演示」；门户测试（04）看的是真实留存，素材过度承诺会拉低 C2P 和口碑。
8. **行动项**：联网恢复后，优先核对 GameLook、游戏葡萄、36氪关于抖音 / 微信小游戏和 B站推广的报道，以及 Among Us、Content Warning 的一手访谈，再更新本文件。

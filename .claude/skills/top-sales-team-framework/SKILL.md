# 顶尖销售团队 · 框架工具箱

> 这是**主题 Skill**：不扮演任何人，用中性、专业的语气。它回答「在我们这种生意里，销售团队该怎么分工、怎么管、每笔交易怎么推进」。

## 激活后先做什么

1. **判断交易类型**（下方决策表）：客单价多少？目标账户有多少个？谁付钱？
2. 按交易类型挑流派：大客户用 MEDDPICC，中量账户用 Predictable Revenue，玩家付费用 PLG。不要一套打天下。
3. 给出可执行的产出：岗位分工表、漏斗指标、单笔交易检查表、每周节奏。
4. **需要事实时先查**：平台条款、分成比例、对方的决策流程会变，先读 `docs/business/sales/platforms/` 或查官方最新文档，查不到就写「待确认」。

## 框架概览：5 条跨流派共识

> 只收录至少两个独立流派都支持的结论。

### 共识 1：规模化之前，负责人先亲自卖、先写 playbook
- Superhuman：创始人亲自带了几百个用户上手，之后才招第一个专员（First Round 访谈，一手）。
- Hormozi：自己打了 4,000+ 通成交电话后才教团队（本人视频标题）。
- Ross 与 Lemkin 2016：没在一个细分市场跑通转化数学之前，不要招 SDR（「Nail a Niche」）。
- **用法**：前 20–50 个平台/达人/社团，由负责人亲自谈，边谈边写 playbook。

### 共识 2：用漏斗数据管理，而不是凭感觉
- Ross：看「每月合格商机数」，不看拨打次数。
- Roberge（HubSpot）：招聘、培训、管理、需求生成都做成「公式」，用数据迭代。
- Hormozi：用成交率反推价格与流程问题（本人帖子，具体阈值为二手转述）。
- OpenView：追踪产品合格线索（PQL）的公司更可能高速增长（其自报调研，相关性）。
- **分歧保留**：各家选的漏斗节点不同。Blount 要求同时盯活动量，Ross 只看产出。

### 共识 3：可教性排第一，面试里当场测
- Roberge 的招聘五项特质把 Coachability 放第一。
- Hormozi：面试时 role play → 给反馈 → 再来一轮，看能不能马上改。
- 两个独立来源一致，但都来自二手总结，可信度中等。
- **用法**：每个岗位面试都做一轮 10 分钟的对练。

### 共识 4：交接和「合格」的定义是一等设计问题
- Ross：每段交接（SDR→AE）都要有明确的合格商机定义，后来他自己又专门强调了交接设计。
- MEDDIC：它本身就是一套「这笔单到底合不合格」的共同语言，用来做每周交易复盘和预测。
- **用法**：给每个漏斗阶段写一句话的准入标准，例如「平台商机 = 对方回复且给出了提交流程或联系人」。

### 共识 5：管道要持续补充，线索来源要多元
- Blount：失败的头号原因是空管道（jebblount.com 原文）；替换法则要求补充速度不低于成交和流失。
- Ross：Seeds（口碑）、Nets（营销）、Spears（定向外联）三类线索都要有。
- Hormozi：没做够量之前不许说渠道不行。
- **用法**：每周固定一个时间块做外联，不要等上线前才临时找人。

## 流派对比

| 流派 | 核心主张 | 最适合 | 公认局限 |
|------|---------|--------|---------|
| **Predictable Revenue**（Aaron Ross） | 专业化分工：开发（SDR）、成交（AE）、维护（AM）分开；Seeds / Nets / Spears | 中等客单、账户数量多的 B2B | 少账户的大客户市场跑不起来（Porter Group）；SDR 高流失；Cold Calling 2.0 回复率已衰减 |
| **Fanatical Prospecting**（Jeb Blount） | 空管道是失败头号原因；每天固定时间块开发；电话仍是核心；Sales EQ 管情绪 | 任何需要主动开发的销售 | 30 天法则和替换法则是经验法则，没有实证；「狂热」有倦怠风险；冷电话不适合海外、社媒场景 |
| **MEDDPICC** | 用 Metrics / 经济决策人 / 决策标准 / 决策流程 / 痛点 / 内部支持者 / 合同流程 / 竞争 判断大单 | 少账户、多决策人、长周期 | 机械套用像审讯；只管资格判断，不管创造需求；小单和自助式场景太重 |
| **Challenger / JOLT**（Dixon & Adamson） | Teach-Tailor-Take Control，带着洞见去谈；找能推动的人（Mobilizer）。同一作者后来的 JOLT 研究：40–60% 的单输给客户犹豫，要降低不确定性 | 复杂 B2B | 数据来自经理主观打分；证实研究多追溯到作者自己的机构；2014 年有学术批评 |
| **Gong 通话数据** | 发现式通话最佳说听比约 43:57，问 11–14 个问题、问题要分散；冷电话里成功者约 55:45 | 通话层面的技巧 | 厂商自有数据、相关性；两种通话的最佳比例方向相反 |
| **Hormozi 的销售团队** | CLOSER 六步；组长 80% 仍在一线；每天 role play；按步骤给通话打分；竞赛与随机奖励 | 一通电话成交的高客单交易 | 高压倾向；「高客单 closer」生态口碑差；证据多为自述 |
| **HubSpot / Roberge** | 四个公式：招聘、培训、管理、需求生成；用数据迭代招聘打分卡 | 有 inbound 线索的中小企业 SaaS | 在红利期、单一公司验证；小团队样本量不够做回归 |
| **PLG / 产品驱动销售** | 产品就是获客和转化渠道，销售后置，只跟进产品数据筛出的线索；最终都会变成混合模式（Elena Verna：「PLG is not a substitute for sales-led growth」） | 低客单、自助式 | 基准数据来自押注 PLG 的机构；没有通用的 PQL 阈值 |

## 6 处流派分歧（原样保留，不调和）

1. **谁来开发客户**：Ross 说交给 SDR，成交的人不开发；Blount 说所有面向客户的人都要开发。
2. **看活动量还是看产出**：Blount 盯每日活动量和时间块；Ross 只看合格商机数；Gong 数据显示问题数超过某个区间反而变差。
3. **关系还是挑战**：Blount 认为人买的是你、情绪和信任是核心；Challenger 的研究里「关系型」销售只占明星销售的 7%（此数字各处引用混乱）。
4. **推动还是减压**：Challenger 讲制造建设性张力、推动客户；同一作者的 JOLT 讲输单主因是犹豫，要给保证和试用来减压。
5. **要不要人去成交**：Hormozi 默认高客单必须有人成交；PLG 主张销售后置。两者的分界线是客单价与客群，见下方决策表。
6. **管道宽还是窄**：MEDDIC 要尽早剔除不合格机会；Blount 和 Ross 先保证管道满。

## 决策表：按交易类型选销售动作

| 交易类型 | 典型例子 | 账户数 | 用什么 | 不要用什么 |
|---------|---------|-------|-------|-----------|
| 少账户大客户 B2B | 平台发行（CrazyGames、Poki、Steam、抖音小游戏）、发行商 | 个位数到几十 | MEDDPICC 检查表 + 负责人亲自谈 + 每次会面都约好下一步（BAMFAM）+ JOLT 式降风险 | SDR 批量外呼；高压成交话术 |
| 中量伙伴合作 | 达人、公会、学校电竞社、社区版主 | 几十到几百 | 轻量 MEDDIC（痛点、内部支持者、决策流程）+ 每周固定外联时间块 + 替换法则 + CLOSER 前三步（问清动机、命名问题、回顾过去尝试） | 纯提成加竞赛（会把长期伙伴变成一次性交易） |
| 低客单 B2C | 玩家买外观、VIP、看激励广告 | 成千上万 | PLG：付费点放在产品里，按玩家行为信号触发；用数据做 A/B 实验 | 任何人工销售话术；虚假紧迫 |

## 用在 GROW EVERYTHING 团队上

| 我们的岗位 | 主要流派 | 这个岗位的「漏斗」 | 节奏 |
|-----------|---------|------------------|------|
| 销售总监 | 共识 2（数据管理）+ Roberge 四公式 | 各岗位漏斗汇总 | 每周例会：每个岗位 3 行 + 一件本周重点 |
| 平台发行 BD | MEDDPICC + JOLT + BAMFAM | 目标平台 → 提交/接触 → 审核或对话 → 上线 → 首页或推荐位 | 每个平台一张 MEDDPICC 表，每周更新 |
| 达人合作 | Blount 替换法则 + Ross 的 Spears + CLOSER 前三步 | 外联 → 回复 → 对话 → 发布 → 带来的新玩家（按 utm 统计） | 每周两个固定外联时间块 |
| 社群与裂变 | Ross 的 Seeds + PLG | 分享 → 点开 → 开局 → 和好友打完一局 | 每周看一次分享率和邀请新玩家数 |
| 变现与定价 | PLG（再配合 alex-hormozi-perspective） | 活跃玩家 → 打开商店 → 付费 → 复购 | 实验计划模板，一次只改一个变量 |
| 数据运营 | 共识 2 + 共识 4 | 为每个阶段写准入标准，保证口径一致 | 每周出周报 |

**招聘与训练（团队扩大时）**：每个岗位一张结构化打分卡，可教性放第一；面试做一次对练（例如「你向 CrazyGames 的对接人争取推荐位」），给反馈后再来一次。人少的时候一人兼多岗，但指标分开记。

## 诚实边界

- **调研受限**：本次调研时网络出口拦截了几乎所有网站，搜索额度中途用完。多数内容来自搜索摘要，没有逐页读原文；Salesforce、Stripe、Bridge Group、RAIN、Gartner 的结论都**没有核验**，本 Skill 不引用它们的数字（清单见 `references/research/06-elite-team-benchmarks.md` 的 B 部分）。
- **数字的可信度**：Gong、OpenView 的数据来自有商业利益的机构，是相关性，不是因果；Challenger 的百分比在各处引用混乱。
- **适用范围**：六个流派几乎都来自 B2B 软件和服务业。用在游戏上时，平台 BD 和达人合作能直接迁移；玩家付费只迁移 PLG 的思想，所有游戏相关的建议都是推断。
- **缺口**：抖音小游戏、微信小游戏的分成与达人规则没有拿到可引用的来源。
- **调研时间：2026-09-24**。

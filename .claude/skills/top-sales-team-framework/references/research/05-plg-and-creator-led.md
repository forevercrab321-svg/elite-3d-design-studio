## 1. 核心论点

### 1A. PLG / PLS 这一派
1. **产品本身就是主要的获客和转化渠道，销售后置。** OpenView 的说法是 PLG 公司"hire sales last"，用产品数据挑出 PQL，例子是"同一个账户里出现 5 个用户就通知销售"【一手：Kyle Poyar 在 Pocus AMA 的发言】 https://www.pocus.com/blog/product-led-sales-pls-ama-kyle-poyar-openview-pls-benchmarks
2. **PLG 做到后来都会变成混合模式。** OpenView 2022 Product Benchmarks（调查 450+ 家软件公司）的结论是：有效的 PLG 需要自助 + 销售介入，而不是纯自助；同一份报告称 PLG 公司的收入倍数高 80%【一手报告，经摘要】 https://openviewpartners.com/blog/your-guide-to-product-led-growth-benchmarks/ ； https://amplitude.com/blog/benchmark-product-led-growth
3. **追踪 PQL / PQA 的公司更可能高速增长。** OpenView 基准数据称：追踪 PQL 或 PQA 的公司，快速增长的可能性提高 61%【一手报告，经摘要；是相关性不是因果】 https://openviewpartners.com/2023-product-benchmarks/
4. **PLG 不能替代销售，也不适合所有公司。** Elena Verna："PLG is not a substitute for sales-led growth"；PLG 不是便宜的 pipeline，也不是快速变现的办法；PLG 公司很少一直保持纯 PLG【一手】 https://www.elenaverna.com/p/product-led-growth-is-many-things ； https://amplitude.com/blog/not-all-companies-should-do-plg ； https://www.elenaverna.com/p/why-when-and-how-to-add-sales-to
5. **Product-led sales：两种动作各管一段客群，互相补充。** 产品驱动和销售驱动适用于不同的客群、角色和用例，应该互补，不该互相竞争或替代【一手】 https://www.lennysnewsletter.com/p/the-ultimate-guide-to-product-led

### 1B. 高接触的反例：Superhuman
6. **规模化之前先做"不可规模化"的人工上手。** Superhuman 强制每个新用户做 30–60 分钟的 1:1 onboarding 通话；创始人亲自带了几百个用户上手之后才招第一个 Onboarding Specialist；高峰期有几十名专员，每周给几千名付费用户做上手【一手：First Round Review 对 Vohra 的访谈】 https://review.firstround.com/superhuman-onboarding-playbook/
7. **PMF 可以量化。** Vohra 用"没有这个产品会非常失望"的比例作为 PMF 分数，一年内从 22% 做到 58%（Product-Market Fit Engine，4 步）【一手】 https://review.firstround.com/how-superhuman-built-an-engine-to-find-product-market-fit/

### 1C. 游戏发行 / 创作者驱动这一派
8. **Web 游戏平台把"发行"做成数据门槛。** CrazyGames：上传构建 → QA 审核（反馈通常 1–2 天）→ Basic Launch 不接 SDK 先测玩家反应 → 表现好才邀请 Full Launch，接入 SDK 开始分成【二手指南，流程与官方门户一致】 https://app.cinevva.com/guides/publish-game-crazygames ；官方门户 https://developer.crazygames.com/
9. **Poki 是"签开发者"而不是签单个游戏。** 所有游戏都人工挑选，上线的游戏保证上首页推荐；有 playtest 工具，几小时内给出真实玩家的会话时长、流失点和录屏，不强制在 Poki 发行【一手官方文档】 https://developers.poki.com/guide/working-with-poki ；"We sign a developer more so than a game"【二手，带赞助性质的报道】 https://www.eu-startups.com/2026/04/how-amsterdam-based-poki-is-becoming-one-of-the-best-launchpads-for-indie-game-developers-in-europe-sponsored/
10. **创作者分成是标准化产品，比例很低。** Epic Support-A-Creator：Fortnite 内使用创作者码的消费，5% 计给创作者；Epic 商店游戏由开发者自定比例，最低 5%；码有效 14 天；申请门槛是某一平台 1,000+ 粉丝；12 个月内满 $100 才打款【一手官方】 https://sac.epicgames.com/overview ；AppleInsider 批评"只有 5%"【二手】 https://appleinsider.com/articles/22/06/27/epics-support-a-creator-program-pays-out-only-5-of-game-content-makers-sales
11. **主播需要能玩的东西。** Chris Zukowski："a streamer can't play screenshots or a trailer"——demo 是 2020 年以后独立游戏的主流打法（meta）；先看契合度（主播是否常播这个品类）再看覆盖面【一手：howtomarketagame 与播客】 https://howtomarketagame.com/ ； https://www.gamedeveloper.com/marketing/game-developer-podcast-36-indie-marketing-advice-from-chris-zukowski

## 2. 自创 / 核心术语

| 术语 | 含义 | 出处 |
|---|---|---|
| **PLG**（Product-Led Growth） | 产品是获客、激活、变现的主引擎 | OpenView 推广（Blake Bartlett 提出）【一手】 |
| **PQL / PQA** | Product-Qualified Lead / Account：高使用度 + 符合 ICP 和 / 或有购买意向 | https://openviewpartners.com/2023-product-benchmarks/ ；定义见 dock.us【二手】 https://www.dock.us/library/product-qualified-leads |
| **PLS**（Product-Led Sales） | 销售只跟进产品数据筛出来的账户 | Verna / Pocus【一手 / 商业偏向】 |
| **Sales-assist** | 销售辅助自助转化，不从零发起 | Verna 相关文章【一手】 |
| **PMF Engine / 40% 失望线** | 量化 PMF 的调查 + 4 步优化 | Vohra【一手】 |
| **Basic Launch → Full Launch** | CrazyGames 的两阶段上线 | 【二手 / 官方门户】 |
| **Creator Code / SAC** | 玩家输入创作者码，创作者拿分成 | Epic【一手】 |
| **Curator Connect** | Steam 向鉴赏家发 key 的官方工具 | 二手 https://www.immutable.com/guides/game-influencer-marketing 【商业偏向】 |

## 3. 团队结构与岗位（PLS 型）

【二手 + 推测，综合 Pocus / Verna / OpenView】

```text
Growth / Product（负责自助漏斗：激活、付费墙、升级提示）
Data / RevOps（定义 PQL 评分，把使用数据同步到 CRM）
Sales-assist / PLS reps（只跟进 PQL：团队邀请、接近用量上限、看定价页、企业域名邮箱）
Enterprise AE（大单扩张：Notion 从已有的 power user 切入企业单）
Onboarding / CS（Superhuman 式的高接触上手，可选）
```

- PQL 信号：团队邀请、功能采用、接近用量上限、看定价页、企业域名邮箱【二手，商业偏向】 https://www.dock.us/library/product-qualified-leads
- Notion：挑出符合企业 ICP 的 power user（PQL），借他们打更大的单【二手，商业偏向】 https://www.pocus.com/blog/product-led-sales-playbook-examples
- Figma：根据使用数据把免费版从"2 编辑者 + 无限文件"改成"无限编辑者 + 2 个文件"，让协作本身成为升级动力；称 PLS 来源的企业账户 NRR 超过 150%【二手，商业偏向，数字未核实】 同上 + https://www.mindtheproduct.com/beyond-product-led-growth-diversifying-strategies-with-notion-and-figma/

**游戏发行 BD 岗位（推测）**：平台关系（对接 Poki / CrazyGames 的 account manager）→ 数据（playtest、留存）→ 创作者关系（达人名单、key 发放、分成码）→ 社区（Discord / 公会）。

## 4. 关键指标与节奏

| 指标 | 说明 | 出处 |
|---|---|---|
| PQL 数 / PQL→付费转化 | PLS 的核心漏斗 | OpenView【一手】 |
| "同账户 5 个用户"触发 | 示例阈值，不是通用标准 | Poyar【一手】 |
| NRR | 扩张型 PLS 的结果指标 | Pocus【商业偏向】 |
| PMF 分数（非常失望 %） | 按月追踪，目标 ≥40% | Vohra【一手】 |
| Web 游戏：会话时长、流失点、留存 | Poki playtest / CrazyGames Basic Launch 用来判断能不能进下一阶段 | 【一手 / 二手】 |
| Steam：wishlist | Zukowski 的案例 Song of Iron 上线前挂页 18 个月，攒了 89,082 个 wishlist；旧 wishlist 不会"过期"；建议上线前 6–12 个月以上开 Coming Soon 页 | 二手转述 Zukowski https://accelerator.xsolla.com/blog/howtomarketagame |

**平台分成（B2B 谈判的底牌）**
- Poki：从 Poki.com 或 Poki 营销带来的用户 50/50；开发者自己带来的用户（书签、搜索、社媒、自有社区）开发者拿 100%【一手官方】 https://developers.poki.com/guide/working-with-poki
- CrazyGames：官方文档不公开比例；某次 Game Jam 条款写的是广告 60% / 内购 70% 给开发者；无上架费、**不要求独占**；每月通过 Tipalti 结算，€100 起付；自称 5,000 万 MAU，Tier-1 市场占比高【二手 + 官方自述】 https://app.cinevva.com/guides/web-game-monetization ； https://docs.crazygames.com/faq/
- 独占换资源：二手资料称 Poki 和 CrazyGames 都会给独占游戏更好的条件（首页位、精选合集）【二手，未见官方条款】 https://www.abratabia.com/web-game-monetization/licensing-to-portals.php

## 5. 招聘 / 培训 / 激励

- **PLS 销售要会看数据**：销售不从冷启动开始，而是从使用数据切入；要会读产品数据、会做 sales-assist，而不是会打陌生电话【推测，基于 Verna / Pocus】
- **Superhuman 的做法**：创始人先亲自做几百次 → 写成 playbook → 再招专员。先有打法再招人【一手】
- **创作者激励**：标准做法是创作者码 + 分成（Epic 最低 5%）；Zukowski 系的建议是先免费发 key、用 Curator Connect，等看到 wishlist 转化的证据再做付费赞助【二手，商业偏向】 https://www.immutable.com/guides/game-influencer-marketing
- 本轮**没有找到** PLG 公司具体提成结构的一手资料（比如 PQL 成交怎么分佣）。

## 6. 成功案例

- Superhuman：高接触上手 + PMF 分数 22%→58%【一手】
- Figma / Notion：PLS 扩张到企业单【二手，商业偏向】
- Poki：自称每月 10 亿次游戏游玩（二手报道标题）【二手】 https://techfundingnews.com/browser-gaming-website-poki-won-big-at-the-dutch-game-awards-celebrating-hitting-1-billion-monthly-plays/
- 本轮**没有核实到**的典型案例（待补）：Among Us 2020 年靠主播爆发；抖音小游戏的达人分成条款；.io 类游戏（agar.io / Krunker）靠 YouTuber 起量。

## 7. 批评与局限（必须）

1. **PLG 被神化了。** Verna 自己列了"PLG 不是什么"：不能替代销售、不便宜、不快、不适合所有业务【一手】
2. **基准数据的利益相关。** OpenView 是押注 PLG 的风投，Pocus 卖 PLS 软件，"61%""80% 倍数""150% NRR"都是自己报告的调研或客户案例；样本存在幸存者偏差，而且是相关性【推测】
3. **PQL 阈值没有通用值。** "5 个用户"只是示例；Pocus 也承认 PLS 不只是一个 PQL 分数【二手】 https://www.pocus.com/blog/product-led-sales-playbook-examples
4. **Superhuman 模式很贵。** 几十名 onboarding 专员对应的是高客单订阅（个人 $30/月级别）【推测：价格是训练知识，未核验】；免费游戏照搬就是亏本
5. **创作者分成比例低，达人议价空间有限。** Epic 的 5% 被批评太低【二手】；对小开发者来说，达人更在意内容效果而不是分成【推测】
6. **平台依赖。** Poki 只对平台带来的流量分 50%，排他资源换的是首页位；对平台来说是"挑开发者"，开发者议价权弱【推测】
7. **本轮证据缺口**：抖音小游戏 / 微信小游戏的分成与达人任务，没有拿到可引用的来源（搜索配额用完），不下结论。

## 8. 与其他流派的分歧

| 议题 | PLG / 创作者派 | 对立方 |
|---|---|---|
| 销售什么时候进场 | 最后；只跟进 PQL | Hormozi：高客单靠人主动成交（04）；Roberge：先建 inbound + 销售团队（06） |
| 线索来源 | 产品使用数据 / 创作者内容 | Hormozi 的 Core Four 包括冷外联和付费广告（04） |
| 规模化方式 | 产品和内容规模化 | Superhuman 反其道：先做不可规模化的人工上手（PLG 阵营内部的分歧） |
| 定价谈判 | 平台条款大多是标准化的（50/50、60/70），BD 谈的是独占换资源 | 传统 B2B 每单谈判 |
| 衡量 | NRR、PQL 转化、wishlist、留存 | 销售派：通话数、成交率 |

## 9. 对 GROW EVERYTHING 销售团队的适用性（【推断】）

- **B2C（外观 / VIP）本质上就是 PLG**：付费墙、升级时机、"接近限制"的提示都放在游戏里面；玩家的"PQL"信号可以定义为：连续 3 天回访、加过好友 / 组过队、打开过商店页、在某个成长阶段卡住。这些都是【推断】的候选，需要埋点验证
- **平台 BD = 用数据说话**：Poki / CrazyGames 都有 playtest / Basic Launch 门槛。BD 的"销售材料"不是 deck，而是留存和会话时长。所以 BD 岗位最重要的是先把游戏过了 playtest 门槛，再谈独占换首页位【推断，基于一手条款】
- **分成结构要算清楚**：Poki 对自带流量给开发者 100%，所以达人 / 社群带来的直链流量在 Poki 上更值钱。这把"平台 BD"和"达人合作"两条线连起来了：达人引流 → 走自带流量通道 → 分成更高【推断，需向 Poki 确认归因方式】
- **非独占优先**：CrazyGames 不要求独占，可以多平台并行测试；是否用独占去换首页资源，等拿到两边的 playtest 数据再决定【推断】
- **达人合作**：参考 Epic SAC 做创作者码（码有效期、最低分成 5–10%、1,000 粉丝门槛），加上可玩的 demo 链接（"streamer can't play screenshots"）；学校电竞社 / 公会可以用同一套码系统追踪归因【推断】
- **Superhuman 式的"创始人亲自做"**：前 20–50 个达人 / 社团由负责人亲自谈，写成 playbook 再交给岗位【推断】
- **不适用**：企业级 PQL→AE 的扩张动作，游戏没有"席位扩张"这回事；公会 / 学校可以类比为"账户"，但付费主体是个人【推断】

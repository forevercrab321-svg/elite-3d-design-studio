## 1. 核心论点（反复出现 = 真信念）

### 1.1 失败的头号原因是「空管道」
- 引语：「The number one reason for failure in sales is an empty pipe」，且空管道的根因是「failure to consistently prospect」
  - 来源：Blount 博客文章同名页 https://jebblount.com/the-number-one-reason-for-failure-in-sales/ 【一手】；亦见书目页 https://jebblount.com/product/fanatical-prospecting/ 【一手】
- 这句话在其书、博客、播客中反复出现，是本流派的「第一信念」。【二手：多份读书笔记一致】

### 1.2 开发是纪律，不是技巧——必须天天做
- 「Fanatical」的含义：把 prospecting 当作每日不可协商的时间块，而非「有空再做」。
- 反面教材：成交旺季停止开发 → 90 天后管道枯竭 → 绝望（desperation）→ 更差的成交。
  - 来源：https://uri.medium.com/the-first-lesson-from-fanatical-prospecting-8c9f9caeecbf 【二手】；https://newsletter.outbound.kitchen/p/fanatical-prospecting-jeb-blount 【二手】

### 1.3 多渠道平衡，但电话仍是核心
- Balanced Prospecting：电话、面访、邮件、社交销售、短信、转介、社交活动、inbound、展会、冷电话混合使用；但在 golden hours 里应优先「最能推动结果」的渠道（电话）
  - 来源：https://readingraphics.com/book-summary-fanatical-prospecting/ 【二手】；https://www.goodreads.com/book/show/31184382 【二手】
- 冷电话「永不死」：Blount 专门撰文/节目论证 cold calling will never die
  - 来源：https://salesgravy.com/why-cold-calling-will-never-die-ask-jeb/ 【一手】

### 1.4 开发不是 SDR 的专属工作
- Blount 立场：prospecting 从来不只是 SDR 的活；AE 与 KAM 也拥有自己的 pipeline；自己掌控管道的 AE 比「等交接」的 AE 赚得多；KAM 通过冷电话进入既有客户的新部门/新决策人，这是扩张收入的来源
  - 来源：https://salesgravy.com/building-pipeline-from-zero-first-time-sales-hire-ask-jeb/ 及同站 Ask Jeb 系列（搜索摘要）【一手·摘要转述，未核读原文措辞，不作引语】

### 1.5 情绪管理决定上限（Sales EQ）
- 定义引语：「Sales EQ is the ability to manage your own disruptive emotions while at the same time accurately interpreting and responding to the emotions of stakeholders.」
  - 来源：搜索摘要转引自 *Sales EQ*（https://sobrief.com/books/sales-eq 、https://invoiceninja.com/ninja-book-review-sales-eq/ ）【二手转引一手】
- 需要压制的「disruptive emotions」：恐惧、绝望（desperation）、执念/依附（attachment）等 【二手】
- 买方观：人凭情绪行动、用逻辑合理化；不要卖产品功能，而是创造让买方情绪上满意的体验 【二手·书评摘要】
- 神经科学包装：以杏仁核（amygdala）忽略无聊模式、对新异信息反应来解释为何「套路化开场」失效 【二手·书评摘要；该神经科学说法的严谨性未核验】
- 与 1.1 的连接：空管道 → 绝望 → 绝望是最具破坏性的情绪 → 降低成交率。开发纪律本身就是情绪管理工具。【二手 + 推测串联】

## 2. 自创术语

| 术语 | 含义 | 来源 / 可信度 |
|---|---|---|
| **30-Day Rule（30 天法则）** | 任意 30 天内的开发工作，会在之后 90 天体现为成交；今天的电话是三个月后的收入 | https://uri.medium.com/the-first-lesson-from-fanatical-prospecting-8c9f9caeecbf 【二手】；https://readingraphics.com/book-summary-fanatical-prospecting/ 【二手】 |
| **Law of Replacement（替换法则）** | 必须以不低于成交/流失的速度补充管道里的机会，否则管道会慢慢枯竭 | 同上 【二手】 |

| **Balanced Prospecting** | 多渠道组合，不押单一渠道 | 同上 【二手】 |
| **Prospecting Pyramid（开发金字塔）** | 按购买可能性把潜客分 6 层，顶层为临近决策的高度合格潜客与 inbound/转介 | 同上 【二手】 |
| **Sales EQ** | 销售专属情绪智力（见 1.5） | *Sales EQ* 【二手转引】 |
| **Ultra-High Performers** | Sales EQ 书中对顶尖销售的称呼 | Amazon 书名 【一手·书名】 |
| **H.I.P.S. Prospecting Method** | Sales Gravy University 课程名（具体内容未查到） | https://www.salesgravy.university/pages/jeb-blount 【一手·仅名称】 |
| **Sales Blitz** | 集中时段团队突击开发/唤醒冷线索 | Sales Gravy 播客条目 https://salesgravy.com/podcasts/ 【一手·仅标题】 |

## 3. 团队结构与岗位分工

- Blount **不主张** Ross 式「AE 不开发」的严格分工；他接受 SDR 存在，但认为每个面向客户的岗位（SDR、AE、KAM）都要有开发职责与开发时间块 【一手·摘要转述】
- 管理者角色：确保团队的 golden hours 不被内部会议、CRM 录入等 platinum 事务侵蚀；组织 blitz 集中开发 【二手 + 播客标题】
- 首位销售/小团队：Ask Jeb 专门讨论「首个销售招聘如何从零建管道」，结论仍是亲自、持续、多渠道开发 【一手·标题 + 摘要】
- 【推测】结构上更接近「全员开发 + 按客户层级分工」，而不是「按漏斗阶段分工」。

## 4. 关键指标（KPI）与节奏

| 指标/节奏 | 说明 | 可信度 |
|---|---|---|
| 每日开发时间块 | 每天固定的 golden hours 开发时段，不可协商 | 【二手】 |
| 活动量（拨打、联系、触达数） | Blount 重视活动量纪律；活动是可控变量，结果不可控 | 【二手·读书笔记普遍概括】 |
| 管道补充率 ≥ 成交/流失率 | Law of Replacement 的量化形式 | 【二手】 |
| 30 / 90 天滞后 | 用 30 天开发量预判 90 天后结果 | 【二手】 |
| 渠道配比 | Balanced Prospecting，按客户层级（金字塔）分配渠道与频次 | 【二手】 |

- 未找到 Blount 给出的普适「每天 X 通电话」硬数字的可靠出处，故不写。【说明】

## 5. 培训与招聘方法

- 培训：Sales Gravy 线下培训 + Sales Gravy University 在线课程；可按行业、客户群、岗位、销售流程定制 【一手】https://jebblount.com/jeb-blount-sales-training/ 、https://salesgravy.com/teams/jeb-blount/
- 训练重点：开发纪律（时间块、渠道话术）、情绪控制（Sales EQ）、异议处理（*Objections*）【一手·书目 + 二手】
- 招聘：Blount 在播客中称招聘「一半流程、一半直觉」，没有万能公式，但正确方法能显著提高命中率 【一手·播客摘要】https://podcasts.apple.com/us/podcast/sales-gravy-jeb-blount/id219558725
- 【推测】从其体系推出的招聘画像：自驱、抗拒绝、能忍受重复性高频触达的人——这与 Ross 把 SDR 当「新人起点岗」的思路不同：Blount 要求**所有**销售都具备这种素质。

## 7. 批评与局限（必须）

1. **渠道时代性**：书出版于 2015 年；有读者评论称冷电话属于上个世纪的首选方式，「让销售团队去给黄页/过时 CRM 上随机的未合格买家打电话」如今显得荒诞
   - 来源：StoryGraph 读者评论 https://app.thestorygraph.com/book_reviews/80d68a19-b5a6-4472-bca4-fdc13b67650f 【二手·读者评论，代表性有限】
   - 反方：Blount 坚持冷电话永不死（1.3）。**矛盾保留。**
2. **「狂热」本身是风险**：有评论认为唯一问题就是「fanaticalness」——开发重要，但没人该把所有清醒时间都投入 【二手·读者评论】；【推测】与 01 文件中 SDR burnout 数据叠加看，高强度活动量文化有倦怠风险
3. **写作与论证质量**：有读者批评章节开头用词典定义、莎士比亚名句等，论证偏励志而非实证 【二手】https://www.goodreads.com/en/book/show/26270465-fanatical-prospecting
4. **实证不足**：30 天/90 天、替换法则属于经验法则，未找到基于数据集的验证研究；「30→90」的滞后长短显然依赖销售周期（快消 vs 企业软件差异巨大）【推测】
5. **Sales EQ 的神经科学包装**：杏仁核等解释是通俗化类比，未核验其学术依据 【推测】
6. **活动量导向 vs 质量导向**：Gong 数据显示「问题数量」超过某区间反而下降（见 03），说明单纯加量不必然提升结果 【二手串联 + 推测】

## 8. 与其他流派的分歧

| 议题 | Blount | 对立/不同立场 |
|---|---|---|
| 谁来开发 | 所有面向客户的人 | Ross：专业化，AE 不开发（01） |
| 主渠道 | 电话为核心的多渠道 | Ross：邮件优先 Cold Calling 2.0（01） |
| 管理抓手 | 活动量与时间块纪律 | Ross：只看产出（合格商机）；MEDDIC：看商机质量（03） |
| 成交观 | 情绪驱动、关系与信任（People Buy You / Sales EQ） | Challenger：关系型销售（Relationship Builder）最不可能是明星，仅占 7%（03）——**直接冲突** |
| 开发 vs 资格判断 | 先保证管道满 | MEDDIC：宁可管道少，也要尽早剔除不合格机会（03） |

## 9. 对 GROW EVERYTHING 销售团队的适用性（【推断】）

**适用：**
- **30 天法则 / 替换法则 → 达人与公会合作管道**：达人合作从首次接触到上线内容通常有数周滞后；如果只在版本上线前临时找人，上线后就没人发。应每周固定时间块联系新达人/公会/学校电竞社，保持「待合作名单」持续补充。
- **Balanced Prospecting**：B 站/抖音/YouTube 达人、Discord/QQ 群公会、学校社团、游戏媒体——不押单一渠道，这对 .io 游戏尤其重要（平台推荐位不可控）。
- **Golden Hours**：小团队里开发者兼 BD，最容易被开发任务吞掉对外时间；每周固定外联时间块是低成本、高回报的纪律。
- **Sales EQ**：平台 BD 被拒、达人不回、玩家差评都会引发「绝望」情绪；「管道满 → 不绝望 → 谈判姿态好」这一逻辑在平台发行谈判（分成、独占期）中有直接价值。
- **KAM 在既有客户内开发**：已合作的平台（如某 Web 游戏平台）内部还有其他资源位、活动、地区站点，可持续挖掘。

**不适用 / 需改造：**
- **冷电话**：面向平台、海外达人、学生社团几乎不适用；替换为邮件、平台开发者后台、社媒私信、Discord。
- **高强度活动量 KPI**：对 B2C 玩家付费无意义（没有人工销售环节）；对达人外联，应以「合作上线数、带来的新增玩家」为主指标，活动量仅作过程监控。
- **「狂热」文化**：独立/小团队首要资源是开发时间，不能照搬「每天大量时间外联」；建议【推断】按周而非按天设开发时间块。

## 0. 这份计划的前提与诚实边界

- **目标**：7 天 1000 名新用户，短视频是第二大来源。本文**不预测**短视频能带来多少用户——没有历史数据，任何数字都是编的。第 3 天起用真实数据（见 §5）判断这个渠道该加码还是降级。
- **归因现实**：
  - TikTok 视频正文和评论里的网址**不能点击**，唯一可点的入口是主页链接（见 §1.3）。一个主页只能放一个链接，所以**无法做到每条视频一个独立 utm**。本计划用「**每天换一次主页链接的 `utm_campaign`**」做到按天归因，再用发布时间窗口粗略对应到单条视频。
  - 抖音 / 小红书的规则限制站外导流（见 §1.3），中文号在这 7 天里**主要作用是品牌曝光和微信口碑扩散**，直接可归因的访问会很少。这一点先讲清楚，避免后面误判。
- **不做的事（红线）**：不说「百万人在玩」「全网爆火」之类没有数据支撑的话；视频里如果对手是 AI 机器人，字幕不写「真人」「陌生网友」；游戏里做不到的画面不拍、不伪造；加速画面在角落标注「×N 倍速」。
- **游戏事实核对**（写脚本前按代码核实过，避免字幕说错）：
  - 三座联机城市：上海（东方明珠）、纽约（帝国大厦）、巴黎（埃菲尔铁塔）。地标被拆完后会出现 「拆除东方明珠！/ EIFFEL TOWER DOWN!」 横幅，本局结束。一局最长 300 秒。
  - 最多 4 台机器同城，大一圈（直径 ≥ 1.25 倍）就能吃掉对手。**被吃的一方像气球一样爆开，吃的一方头顶冒出「嗝~ 😋 / BURP~ 😋」**，被吃方 3 秒后在别处重生（每人 3 条命）。所以字幕写「吃完还打了个嗝」，不写「被吐出来」。
  - 每台机器车顶有会晃动的大眼珠；喇叭（H 键或触屏按钮）：小丑喇叭（默认）、橡皮鸭、自行车铃、悲伤长号、汽笛；表情 😂🤡👋🐷😱📯。
  - 击杀播报有城市梗：上海「把 {v} 当小笼包，一口闷了 🥟」、纽约「把 {v} 夹进热狗吃了 🌭」、巴黎「{v} 变成了 {a} 的可颂 🥐」。
  - 中英双语：链接加 `?lang=en` / `?lang=zh`。手机横屏可玩，无需下载。

### 1.3 链接放置方式与平台规则（含出处）

> 说明：本环境的网络代理拦截了 tiktok.com、douyin.com 开发者站、sproutsocial.com、buffer.com 的页面抓取，以下规则来自这些官方页面在搜索引擎中的摘要，**原文未能直接打开**。发布前请运营人员在手机 App 里再核对一次。

**TikTok**
- 规则：TikTok 官方帮助页「Adding a website link to your profile」的摘要写明：**经认证的企业号（Business Account）可在主页放网站链接；普通账号需至少 1,000 粉丝**。出处：<https://www.tiktok.com/support/faq_detail?id=7581821550328896012>；切换企业号：<https://support.tiktok.com/en/using-tiktok/growing-your-audience/switching-to-a-creator-or-business-account>；企业认证：<https://ads.tiktok.com/help/article/tiktok-business-account?lang=en>。第三方 2026 年指南也一致说个人号仍需 1,000 粉丝（例：<https://stan.store/blog/tiktok-link-bio-requirements-2026-guide/>）。
- **做法**：第 0 天把账号切成**企业号**并提交企业认证，这样 0 粉丝也能挂链接。认证如果没通过，退路是：简介写 "Link in pinned comment ↓"，在置顶评论写纯文本网址（不能点击，但可以复制），并在视频最后 1 秒画面上叠加网址文字。
- ⚠️ **企业号的配乐限制**：企业号只能使用 TikTok 商用音乐库（Commercial Music Library），不能用热门流行歌曲。所以下文所有配乐建议都写成「商用音乐库里的某类曲风」或「游戏原声 / 游戏音效」。游戏本身的喇叭、打嗝、倒塌音效就是最好的声音素材。
- **主页链接（每天换一次 campaign，做按天归因）**：
  ```
  https://grow-everything.vercel.app/game/?lang=en&utm_source=tiktok&utm_medium=bio&utm_campaign=w1_d1
  ```
  第 2 天改成 `w1_d2`，以此类推。游戏埋点会记录 `utm_source / utm_medium / utm_campaign / utm_content`（`game/src/backend/telemetry.ts`），`sessions.utm` 可以按天查。

**抖音**
- 规则：抖音《社区自律公约》（<https://www.douyin.com/rule/policy?activeId=self_decipline>）与抖音开放平台《短视频挂载使用规范》（<https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/operation/platform-capabilities/video/mount-usage-spec>）的摘要都写明：**不得通过网址、二维码等方式诱导用户跳转或下载外部 App，不得引导站外交易**，违规会被删内容、限流、限制功能甚至封号。
- **做法**：
  - 抖音主页、视频画面、评论里**都不放网址和二维码**。
  - 视频引导语用「**主页有玩法介绍**」「**评论区说说你想吃哪个地标**」这类互动话术，不写「点链接」。
  - 真正的转化路径是：看到视频 → 自己搜游戏名 / 朋友在微信里转发链接（游戏内分享面板已支持一键发微信）。
  - 中长期路径：`platform-strategy.md` 里的**抖音小游戏**版本上线后，才能在视频上合规挂载小游戏入口。这是平台发行 BD 的工作，本计划不依赖它。
  - 如果用户愿意注册**抖音企业号（蓝 V）**，企业号主页是否有可合规展示的官网入口，需要在企业号后台核实（**待确认**，不要凭记忆操作）。

**小红书**
- 规则：《小红书社区规范》（<https://agree.xiaohongshu.com/h5/terms/ZXXY20221213003/-1>）的摘要写明：不鼓励发布营销和导流信息。
- **做法**：与抖音一致，不放网址和二维码；用「游戏名 + 城市名」做可搜索的标题，引导用户「评论区交流」。

**结论（给销售总监）**：7 天内**可归因的短视频流量基本都来自 TikTok 主页链接**。抖音和小红书的价值在于测试中文钩子、积累素材，以及带动微信转发。这两个号每天的工作量控制在「剪同一素材的中文版」，不要重新拍。

## 3. 通用创作规则（每条视频都要过）

来自 `mrbeast-perspective` 的框架，已改写成短视频可执行的检查项：

1. **第 1 帧就是概念本身**：不放 logo、标题卡或「Hey guys」。第一帧要么是「小东西 + 巨型地标」同框，要么是倒塌进行到一半的画面。
2. **前 3 秒讲清核心信息**：TikTok 官方创意指南称，CTR 最高的视频中超过 63% 在**前 3 秒**就点明了核心信息（TikTok for Business《9 Creative Tips to drive performance》：<https://ads.tiktok.com/business/library/Auction_Ads_Creative_Tips.pdf>，来自搜索摘要）。
3. **阶梯递进**：易拉罐 → 垃圾桶 → 汽车 → 房子 → 地标。每一级都要比上一级大，刺激强度曲线不能出现平台期。
4. **每 2–3 秒一次注意力重置**：换镜头、音效、字幕跳出、镜头拉远。短视频比 YouTube 长视频更密。
5. **兑现承诺**：钩子承诺了「吃掉埃菲尔铁塔」，视频里就必须真的出现铁塔倒下。不兑现 = 标题党，会同时伤害留存和信任。
6. **结尾做成循环**：最后 1 帧能接回第 1 帧（例如：倒塌后又切回一个小易拉罐），让重播率计入完播。
7. **竖屏安全区**：字幕放在画面中上部，避开底部约 20% 的按钮区和右侧的互动栏。
8. **字幕**：英文每行 ≤ 6 个单词；中文每行 ≤ 12 字。一律烧录进画面（很多人静音刷视频）。

### V01 · D1 · TikTok —— 「这个小机器人要吃掉埃菲尔铁塔」（主推钩子 #1）

- **时长**：24 秒
- **前 1 秒画面（钩子）**：低机位特写，巴黎街道上一台 1 级小机器（直径约 0.35 m，只比旁边的易拉罐大一圈），大眼珠直直盯着镜头；远处背景里埃菲尔铁塔清楚可见。
- **前 3 秒字幕**：`This tiny robot is going to eat the Eiffel Tower.`
- **镜头顺序（逐秒）**
  - 0–1s：S01 低机位，小机器 + 易拉罐 + 远处铁塔同框（定格感，眼珠晃一下）
  - 1–3s：机器吸进第一个易拉罐，体积跳大；字幕保持
  - 3–6s：S05 加速段（右上角标「×12」）：垃圾袋 → 咖啡椅 → 垃圾桶，每次吸入配「啵」音效
  - 6–9s：第一辆车被吸进去，镜头随体型拉远；字幕 `car ✅`
  - 9–13s：路边咖啡馆小楼（Café house）被拆；字幕 `house ✅`
  - 13–16s：机器已经比街区还大，正对铁塔；字幕 `…Eiffel Tower?`
  - 16–21s：S03 铁塔塔腿被扯下，整塔倾倒，「EIFFEL TOWER DOWN!」横幅
  - 21–24s：机器头顶冒出 `BURP~ 😋`，切回一个新的小易拉罐（循环点）
- **需要录的画面**：巴黎 · 一局完整连续录制（S05），从 1 级开局到地标拆完；S01 巴黎开局低机位；S03 巴黎埃菲尔铁塔倒塌（5 级 / 城市级体型）。
- **配乐 / 音效**：前 3 秒只用游戏原声（吸入声 + 眼珠晃动），3 秒起接入商用音乐库里 120–130 BPM 的「逐渐上升」型电子曲；倒塌瞬间音乐停 0.5 秒，只留倒塌声，然后接打嗝声。
- **字幕文案**：`This tiny robot is going to eat the Eiffel Tower.` → `car ✅` → `house ✅` → `…Eiffel Tower?` → `(it burped)`
- **置顶评论**：`Free in your browser, no download 🥫➡️🗼 Link in bio — bring 3 friends and eat each other too.`
- **标签（英）**：#browsergame #iogames #eiffeltower #gaming #indiegame #multiplayer
- **utm**：`utm_source=tiktok&utm_campaign=v01_can_eiffel`

### V02 · D1 · 抖音 —— 「从易拉罐吃到东方明珠」

- **时长**：25 秒
- **前 1 秒画面（钩子）**：结尾先放——东方明珠上球体倾斜、正在倒下的一瞬（0.8 秒），然后硬切到开局的小机器。
- **前 3 秒字幕**：`几分钟前它还在吃易拉罐`（第 0 秒）→ `从头看 👇`（第 1 秒）
- **镜头顺序（逐秒）**
  - 0–1s：S02 东方明珠倾倒中段（冻结 0.2 秒）
  - 1–3s：S01 上海开局，小机器在外滩步道边，旁边是易拉罐
  - 3–7s：S05 加速（标「×12」）：吃易拉罐、自行车、电动车（游戏里的 Bicycle / Scooter）
  - 7–11s：吃上海出租车 / 公交车；字幕 `车：吃了`

## 5. 衡量指标与「数据差时的替换方案」

### 5.1 每条视频看哪些数

| 指标 | 在哪看 | 为什么看 |
| --- | --- | --- |
| **前 2 秒留存**（抖音后台叫「2 秒跳出率」，取 1 − 跳出率；TikTok 看 Analytics 留存曲线在 2 秒处的高度） | 抖音创作者中心 / TikTok Studio 的单条视频分析（字段名以后台实际显示为准） | 判断钩子是否有效 |
| **完播率**（TikTok：「看完整个视频」的比例；抖音：完播率 / 5 秒完播率） | 同上 | 判断视频中段有没有掉线 |
| 平均观看时长 ÷ 视频时长 | 同上 | 与完播率互相印证 |
| 分享数、评论数 | 同上 | 衡量能不能带动传播（本游戏的核心卖点是拉朋友） |
| 主页访问数、链接点击数（TikTok 企业号） | TikTok Studio | 从看视频到点链接的转化 |
| **`lobby_view` / `match_start`（按 `utm_campaign`）** | Supabase `sessions.utm` + `events` | **真正的目标**：来了多少人、有多少人开了局 |

### 5.2 判断线（内部假设，不是行业标准）

没有找到可以引用的「游戏类短视频前 2 秒留存 / 完播」基准，所以下面这些线是**本团队的假设起点**。第 3 天后改成「本账号已发视频的中位数」：高于中位数算好，低于中位数算差。

| 视频时长 | 前 2 秒留存（假设线） | 完播率（假设线） |
| --- | --- | --- |
| ≤ 12 秒 | ≥ 70% | ≥ 35% |
| 13–20 秒 | ≥ 65% | ≥ 25% |
| 21–35 秒 | ≥ 60% | ≥ 15% |

**冷启动说明**：新账号前几条视频的播放量可能很低（几百次），比例指标波动很大。播放不足 500 次时只记录、不下结论。

### 5.3 诊断树（什么数据差 → 改哪里）

| 症状 | 说明问题出在哪 | 替换方案（24 小时内执行） |
| --- | --- | --- |
| **前 2 秒留存低** | 第一帧不够抓人，或者看不懂 | ① 把视频里最强的一帧（倒塌 / 被吃爆开）挪到第 0 帧；② 字幕改成更短的一句冲突句（≤ 6 个英文单词）；③ 去掉所有开场黑场和淡入。用同一素材重新剪一版再发 |
| 前 2 秒好，**完播低** | 钩子有效，但中段节奏掉了（通常是加速段太长或太单调） | ① 砍掉中段 30%；② 每 2 秒插一个吸入 / 字幕跳出 / 镜头拉远；③ 把地标倒塌提前到视频 60% 处出现 |
| 完播高，**分享 / 评论低** | 好看，但没有「想发给朋友」的理由 | 改结尾：加 `tag a friend` / `你会被做成什么？` 这类问句；把朋友互吃的镜头放进结尾 |
| 视频数据好，**`lobby_view` 低** | 转化断在主页 → 链接这一步 | ① 检查主页链接能不能打开、在 TikTok 内置浏览器里能不能玩（用 V11 素材自测）；② 置顶评论写清「link in bio」；③ 简介第一行改成动作句 `Play free 👇` |
| `lobby_view` 高，**`match_start` 低** | 来了但没开局（加载慢、看不懂、手机竖屏卡在旋转提示） | 转给工程团队：查加载时长和 TikTok 内置浏览器兼容性；这不是视频的问题 |
